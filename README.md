# Doremon.ai

An original, child-friendly interactive learning gadget prototype.

## Features
- Math practice and fraction learning
- Science discovery activities
- Creative story maker
- Gadget recommendations based on questions

## Run
Open `index.html` in a browser. No dependencies or API keys needed.

## Deploy
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

This is an educational prototype with rule-based recommendations, not a generative AI service. Do not collect children's personal data. A production children's product needs privacy, safety, and parental-consent review.
